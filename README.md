# APEX — Personal Training
A modern English-language demo landing page built with HTML, CSS, and JavaScript. No dependencies or build step required.

Open dist/index.html or serve the dist directory through an HTTP server.

Customization:
- Replace APEX with the trainer’s real name and brand.
- Add professional credentials, biography, and training locations to dist/index.html.
- Replace the illustrative Unsplash photos with authorized trainer photography.
- The form creates a local, copyable training brief. It does not send or store information.
- Connect a real contact channel before collecting enquiries. For WhatsApp, use an authorized phone number with https://wa.me/NUMBER?text= and encodeURIComponent for the message.
- This demo contains no invented testimonials, qualifications, prices, or client results.

Files: dist/index.html, dist/styles.css, dist/app.js.
